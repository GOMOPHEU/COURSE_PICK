## 2. 서버에서 남은 것

| 순서 | 항목 | 내용 |
|---|---|---|
| 1 | 동행 규칙 적용 | 설정 초안(`docs/recommend-config.draft.json`)의 규칙을 반영함. 가족: 술집 제외, 이동 15분 이하. 연인: 17:00 이후 카페·문화·산책 우선. 모든 동행: 이름·분류의 키워드 가산점. 구글 속성(아이 동반, 단체 이용)과 리뷰 키워드 가산점, 인원수 규칙은 데이터 문제로 보류 |
| 2 | 시나리오 테스트 | 가족 토요일, 연인 평일 저녁, 10대 친구 화요일, 시간 입력 오류 케이스 실행 완료. 남은 것: 시나리오 문서의 기대값 수정(연인 평일 저녁은 17시에 바로 식사, 시간 오류 응답의 `INVALID_INPUT` 코드) |
| 2-1 | 도보 한도 실측 재확인 (후속 과제) | 도보 한도(최소 도보 10분 등)는 후보를 고를 때 추정값 기준이라 경로 검증 후 실측 시간이 최대 15분 안팎까지 나올 수 있음(예: 11분). 엄격히 지키려면 경로 검증 뒤 한도를 넘는 구간의 장소를 제외하고 코스를 다시 짜야 함. 지금은 허용 |
| 3 | 구글 호출 사용량 확인 | 요청마다 검색·상세 조회가 몇 번 나가는지 콘솔에서 확인. 무료 한도(월 약 1,000건) 기준으로 상한 조정 |
| 4 | Gemini 품질 확인과 방향 확정 | 제미나이가 코스를 직접 짜게 해 봤으나 규칙 위반으로 대부분 탈락하고 선택 테마가 빠져, 선택·이유 생성으로 역할을 줄임. 팀과 방향 확인 필요 |
| 5 | 구글 호출 사용량 | 구글 확인 한도를 코스별이 아니라 요청 전체로 공유(`maxGoogleCallsPerRequest` 100, `maxGoogleSearchesPerRequest` 200)하고, 같은 요청에서 한 번 조회한 장소는 뒤 코스가 다시 조회하지 않고 재사용함. 연인 평일 저녁(s2)에서 코스 3개 확인. 요청당 실제 호출 수 기록은 아직 없음 |
| 6 | 영업시간 보강 | 직접 확인한 공식 영업시간을 `config/official-hours.json`에 추가(산책 공원·거리 24시간 개방 처리, 문화 시설 시간·제외 처리). 직접 확인한 정보가 구글 매칭보다 우선. 구글 후보가 1개뿐인 review는 같은 곳으로 봄(`placeMatching.acceptSingleCandidate`). 문화 측정 136곳 기준 62%가 영업시간 판정에 사용 가능 |
| 6 | 시간 오류 응답 코드 | 시간 입력 오류가 `{"error": 메시지}`만 나가므로 문서의 `INVALID_INPUT` 코드와 맞추기 |
| 7 | check19 흐름 팀 공유 | 공유 여부 확인 필요 |

## 4. 문서와 정리 사항

- 할일 목록 v2에 "Node 서버", "OpenAI"로 적힌 곳을 Spring Boot, Gemini로 고치기 (팀 합의 필요)
- 후보 검색 방식 변경 내용을 문서 4-1절에 반영하기. 문서는 "반경 690m, 부족하면 1,000m 한 번"인데 구현은 "거점 ±100m 사각형에서 단계별 확장"으로 바꿈. 밀집 테마에서는 카카오 한도 때문에 반경 확장이 효과가 없다는 이유
- `server/run_log.txt`는 `.gitignore`에 추가함. 이미 올라간 기록은 키가 없어 그대로 둠
- 동행 규칙(2026-11-27 결정): 가족 5곳·15분·술집 제외, 연인 6곳·평점↑·저녁 우선, 친구 6곳·20분·평점↑, 혼자 4곳·15분·거리↑. 값은 `companionRules`에서 조정
- 키가 없어도 시간 형식 검사(종료가 출발보다 늦어야 함, 날짜 형식)를 먼저 하고, 그 다음에 고정 응답을 돌려줌
- 베이커리는 카페 테마로 분류, 리뷰 키워드 가산점(`reviewBonus`)은 끔
- 결정(2026-11-27): 공원·거리는 24시간 개방으로 처리하고, 상가와 하나플레이파크는 제외. 영업시간이 확인되지 않는 장소는 서버에서 제외(`requireKnownHours`)
- 요청 한 번의 구글 호출은 코스 전체 합산으로 상세 100건, 검색 200건. 사용량은 서버 로그에 한 줄로 남음
- `mobilityRules.minimizeWalking.preferShorterWalkTotal`: true면 거리 가중치를 `distanceWeightFactor`(2.0)배로 올려 가까운 후보를 더 우선함(나머지 가중치는 합이 1이 되게 줄임)
- 영업시간 파일의 출처 주소는 참고용이라 그대로 둠. 한국색동박물관은 한국관광공사 기준(화~토 13:00~17:00, 일·월·공휴일 휴관)으로 기입
- 수집 파일(`kakao_all.json`, `reviews_dump.json`) 사용 후 삭제, 공유 금지
- API 키는 환경변수로만 사용: `KAKAO_REST_API_KEY`, `GOOGLE_PLACES_API_KEY`, `GEMINI_API_KEY`. 카카오 키는 팀원3이 재발급, 구글 키는 팀원2가 재발급
