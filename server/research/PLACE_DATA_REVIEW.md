## 서버와 match_places.py 판정 비교

**서버의 실시간 매칭 기능은 없다. 동일 기준으로 동작한다고 말할 수 없다.**

- Spring Boot `server/src/main/java/com/coursepick`에는 카카오 후보 선정만 구현되어 있고, Google Text Search 및 이름 매칭은 없다. `/recommend`는 샘플 응답이다.
- 독립 Java `PlaceLookupService.lookup`은 저장된 `place-mappings.json` 상태를 읽는다. matched만 Place Details로 조회하고, review는 NEEDS_REVIEW로 반환한다. 새 카카오 ID는 MAPPING_NOT_BUILT다. Google 결과를 이름·거리로 다시 매칭하지 않는다.
- `server/tools/check21.py`는 `match_places.py`의 `classify_match`를 직접 import하므로 **이 두 Python 도구의 판정은 동일 함수**다.

현재 Python 기준:

1. 이름 NFKC 정규화, 소문자화, 영문·숫자·한글 외 문자 제거. 괄호 안 내용과 지점명은 제거하지 않음.
2. 정확히 같은 이름이면 40m 이내, 또는 도로명·건물번호 일치 + 150m 이내.
3. 이름 SequenceMatcher 유사도 0.88 이상 + 도로명·건물번호 일치 + 100m 이내도 수용 가능.
4. 순위 점수 = 유사도×0.7 + max(0, 1−거리/300)×0.2 + 주소일치×0.1.
5. 상위 두 점수 차이가 0.08 미만이면 확정하지 않음. 유사도 0.45 이상·500m 이내 후보가 있으면 review, 그 밖은 unmatched.

팀 할일 문서의 '괄호 안 삭제·지점명 제거·완전일치 100m·포함 40m'와는 **서로 다른 알고리즘**이다. 이번 요청은 기준 확인이므로 기존 판정을 임의로 바꾸거나 서버에 새 매칭 알고리즘을 추가하지 않았다.

## 무료 사용 설정

콘솔 접근용 브라우저 호스트가 없고, Google Cloud 키/쿼터 관리 플러그인도 발견하지 못했다. gcloud CLI도 없다. 따라서 **키 제한·일일 쿼터·예산 알림은 실제 변경하지 않았다**. 로컬 .env의 키 존재만 확인했고 값을 출력하지 않았다.

2026-11-26 확인한 [Google 공식 가격표](https://developers.google.com/maps/billing-and-pricing/pricing)에서 Text Search Pro 무료량은 월 5,000건, 영업시간을 포함한 Text Search Enterprise 및 Place Details Enterprise는 각각 월 1,000건이다. 현재 매칭 도구는 이름/주소/좌표를 요청하고, check21과 상세조회 모듈은 영업시간을 요청한다. SKU별 집계이므로 서로 합쳐 'Places는 모두 무료'라고 해석하면 안 된다.

하루 100건이면 31일에 3,100건으로 Enterprise 무료량을 넘을 수 있다. [Google 비용 관리 안내](https://developers.google.com/maps/billing-and-pricing/manage-costs)는 무료량을 31로 나눠 일일 제한을 정하도록 안내한다. 1,000건에 대한 수학적 상한은 32건/일이지만, 다른 프로젝트/키 사용량 및 오차를 감안한 **30건/일 이하 제안**도 전체 계정 사용량 확인 후 적용해야 한다. 이는 설정 완료값이 아니다.

콘솔 연결 후 적용할 구체 항목:

1. 해당 프로젝트의 API 및 서비스 > 사용자 인증 정보 > 실제 서버용 키 > API 제한에서 **Places API (New)만 허용**. 다른 키까지 일괄 변경하지 않음.
2. Maps Platform > 할당량에서 실제 제공되는 일일 제한 항목과 적용 단위를 확인. 무료 전용 목적에 맞게 가장 낮은 SKU 무료량 기준으로 제한하고, 여러 메서드/프로젝트에 걸친 사용은 함께 계산. 일일 제한이 제공되지 않는 항목은 분당 제한만으로 하루 상한을 보장할 수 없으므로 앱 측 영속 카운터/공유 게이트가 필요.
3. Cloud Billing > 예산 및 알림에서 해당 프로젝트·서비스의 실제 비용 알림 설정. [알림 전용 예산](https://docs.cloud.google.com/billing/docs/how-to/budgets)은 자동 차단과 다르다. 0원 목표를 '유료 사용 허용'으로 바꾸지 않고, 콘솔에서 가능한 최소 알림값/0원 지원을 확인해야 한다. 현재 실제 알림 금액은 설정하지 않음.
4. 이번 달 사용량과 적용된 제한을 확인하기 전 API 재실행 보류. 체크21을 여러 번 실행하거나 재시도한 호출도 계정 사용량에 포함해 확인.
