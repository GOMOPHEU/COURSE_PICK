## 영업시간 직접 보강 전후 (2026-11-27)

- 보강 대상: 구글에서 시간을 못 찾는 문화·산책 후보. 웹에서 찾을 수 있는 정보는 모두 입력하고, 못 찾은 곳은 `unconfirmed`로 두어 서버가 제외하게 함
- 직접 입력 파일(`official-hours.json`): 14곳 → 79곳. 이 중 확인 완료 71곳(24시간 개방 32곳, 상시 휴관·제외 12곳, 시간 입력 27곳), 조사 못 함 8곳
- 조사 못 함 8곳: 구 통계국청사, 박규수선생집터, 이상재집터, 학아재미술관, 한글전각미술관, 서울문화홍보원, 예전사, 갤러리더플럭스 (현재 공식 운영 정보를 찾지 못해 일부러 비워 둠)
- 보강 대상 표본 74곳(산책 38, 문화 36)의 직접 입력 현황: 직접 입력 44곳(59%), 조사 못 함 0곳, 입력 없음 30곳(구글 영업시간에 의존). 보강 전에는 이 표본에 직접 입력된 곳이 0곳. 상세는 `hours-fill-status.csv`
- 산책: 표본 38곳 중 31곳을 직접 입력(24시간 개방 등), 7곳은 구글 의존
- 문화 대표 장소 36곳: 쓸 수 있는 곳 23곳(64%) → 33곳(92%)
- 문화 측정 136곳(대표 36 + 나머지 100): 쓸 수 있는 곳 56곳(41%) → 84곳(62%). 구글 후보가 1개뿐인 review를 같은 곳으로 보는 규칙의 효과가 포함됨
- 목표 60%: 문화 62%로 넘김. 나머지 문화 후보 96곳은 측정하지 않음
- 보강 전 수치는 보강 후 수치에서 직접 입력으로 늘어난 곳을 뺀 값으로 계산함. 구글 영업시간 자체는 같은 날 한 번만 측정함
