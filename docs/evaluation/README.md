# 영역 8 평가 표본

- 추출 방식: `kakao_all.json`(카카오 후보 4,844곳, 거점 반경 1.3km)에서 서버와 같은 규칙(궁 하위 건물 제외: `parentPlaceNames` 이름으로 시작하는 더 긴 이름, 그리고 이름 접두 중복 묶기)을 먼저 적용하고, 구분별로 카카오 ID 오름차순 정렬 후 고정 시드로 무작위 추출
- 시드: `20261127` (추출 전에 기록). 구분별 시드는 `"20261127-<카카오 그룹코드>"`, 파이썬 `random.Random(...).sample`
- 1차(1~40번): 음식점(FD6) 15, 카페(CE7) 10, 문화시설(CT1) 8, 관광명소(AT4) 7, 합계 40
- 2차(41~100번): 1차에서 뽑힌 곳을 뺀 나머지에서 시드 `"20261127-extra-<그룹코드>"`로 추가. 음식점 23, 카페 15, 문화시설 12, 관광명소 10
- 합계 100곳: 음식점 38, 카페 25, 문화시설 20, 관광명소 17
- 표본 파일: `eval-sample.csv` (정답 조사 칸은 비어 있음)
- 보고는 구분별로 따로 하고, 틀린 사례도 그대로 기록

- 매칭 기준: 서버가 영업시간까지 판정에 쓸 수 있는 곳(구글 영업시간 확인 + 직접 확인한 공식 정보)
