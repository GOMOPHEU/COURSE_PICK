# 설정 파일 대조 결과

대조일: 2026-11-26 (팀원4 박태성)

`docs/recommend-config.draft.json`(11/22 초안)과 서버가 실제로 읽는 `server/config/coursepick.json`(11/25)을 항목별로 비교했다.

**결론: 앞으로 설정의 기준은 `server/config/coursepick.json` 하나다.** 초안은 이 대조를 끝으로 삭제했다. 지난 내용은 git 기록에 남아 있다.

## 1. 값이 같은 항목

다음 항목은 두 파일의 값이 모두 같다. 보고서와 할일목록에 적힌 값과도 일치한다.

| 항목 | 주요 값 |
|---|---|
| `weights` | 거리 0.25, 보정 별점 0.30, 테마 0.15, 동행 0.15, 영업 확인 0.10, 리뷰 0.05 |
| `rating` | 베이즈 보정 m = 50 |
| `stayMinutes` | 카페 60, 궁 90, 식사 60, 산책 40, 문화 60, 쇼핑 거리 40, 소품샵 20, 작은 유적 30 (분) |
| `timeFit` | 90% 이하 여유, 100% 이하 빠듯 |
| `walkingEstimate` | 직선거리 × 1.3 ÷ 67m/분 |
| `startPoints` | 안국역, 경복궁역, 종각역, 광화문역 |
| `barRule` | "음식점 > 술집" 분류, 이름 키워드 6개 |
| `companionRules`, `ageGroupRules`, `mobilityRules`, `partySizeRules` | 값 같음. 서버 코드에 실제로 적용된 것은 가족(술집 제외, 이동 15분), 10대(술집 제외), 도보 최소화(도보 10분)뿐 |
| `leftoverTime`, `duplicateRule`, `reviewBonus` | 같음 |

## 2. 값이 다른 항목

| 항목 | 초안 | 서버 | 판단 |
|---|---|---|---|
| `region.name` | 안국역 반경 1.3km | 안국역 | 표시용 이름이라 서버 값 사용. 좌표와 반경 1,300m는 같음 |
| `mealWindows` | 시간대만 있음 (점심 11:00~14:30, 저녁 17:00~20:30) | 같은 시간대 + 식사 시작 한도 `latestStart` (점심 13:30, 저녁 19:30) | 서버 값 사용 |
| `candidateSearch` | 반경 690m, 부족하면 1,000m 한 번 | 거점 ±100m 사각형에서 100, 200, 300, 500, 700, 1,000m로 단계별 확장, 결과가 한도를 넘으면 4등분 | 서버 값 사용. 할일목록 v2.1 4-1절에 반영함 |
| 테마 분류 | 초안 `themeMapping` | 서버 `candidateSearch.themes` | 아래 3절 참고 |

## 3. 테마 분류 비교

| 테마 | 초안 | 서버 | 확인할 것 |
|---|---|---|---|
| 카페 | 카페 + "음식점 > 간식"(디저트·베이커리) | "음식점 > 카페"만 | **확인 필요.** 서버의 맛집 테마도 "음식점 > 간식"을 제외하므로 이 분류(제과·베이커리 등)로 등록된 곳은 어느 테마에도 들어가지 않는다. "음식점 > 카페 > 디저트카페"로 등록된 곳은 카페에 들어간다. 11/22 정환님과 정한 "디저트·베이커리는 카페 테마"와 다름 |
| 맛집 | 음식점에서 간식·구내식당·도시락 제외 | 같음 + 카페 제외 | 문제 없음 |
| 산책 | 공원, 테마거리, 산책로 | 같음 + 키워드 "공원", 먹자골목·공원시설물 제외 | 문제 없음 |
| 쇼핑 | 테마거리, 시장, 인테리어장식, 디자인문구, 패션잡화, 복합쇼핑몰 | 키워드 "소품샵", "쇼핑"만 (임시) | 쇼핑 분류 결정(할일목록 4-3, 팀원2) 후 서버에 반영 |
| 역사 | 문화유적, 고궁 | 같음 + 궁 하위 건물을 한 장소로 묶음 | 11/22 결정(하위 건물 제외)과 맞음 |
| 전시·문화 | 문화시설(CT1) | 같음 | 문제 없음 |

## 4. 서버에만 있는 항목

초안 이후 서버 구현 중에 생긴 항목이다. 값은 서버 담당이 관리한다.

| 항목 | 내용 |
|---|---|
| `closedDays` | 휴궁일. 경복궁 화요일, 창덕궁 월요일. 종묘(화요일)는 아직 없음 |
| `planning` | 코스 수 3, 코스당 최소 2곳, 요청당 구글 호출 30건, 카페 하루 3회·4시간 간격, 구글 매칭과 영업시간이 확인된 곳만 사용 등 |
| `routeVerify` | 카카오 경로 API로 긴 구간 3개를 실측 시간으로 교체 |
| `gemini` | 모델 gemini-3.5-flash-lite, 후보 코스 5개 중 3개 선택 |
| `placeMatching` | 매칭표에 없는 장소를 구글로 실시간 매칭, 하루 300회 상한 |

## 5. 팀에 전달할 것

1. 디저트·베이커리("음식점 > 간식")를 카페 테마에 넣을지 서버 담당과 확인 (종욱님, 정환님)
2. 종묘 화요일 휴관을 `closedDays`에 추가할지 확인 (종욱님)
3. 연인·친구·혼자 동행 규칙은 설정에만 있고 코드에는 아직 없음. 동행 규칙 확정 후 반영 (팀원2, 팀원4)
